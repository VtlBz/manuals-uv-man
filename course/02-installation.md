# Курсовые материалы: 02-installation.md

!!! info "Цели модуля"
    После прохождения этого модуля вы сможете:

    - Установить `uv` на свою операционную систему
    - Настроить автодополнение команд в терминале
    - Проверить корректность установки и ориентироваться в справке

---

## Практическое задание

!!! example "Задание: Установка и настройка uv"

    1. **Установите `uv`** с помощью standalone-установщика
       для вашей операционной системы.

    2. **Проверьте установку**, выполнив:

        ```bash
        uv --version
        ```

        Убедитесь, что команда выполняется без ошибок и выводит версию.

    3. **Настройте автодополнение** для вашего shell.

        Определите свой shell:

        ```bash
        echo $SHELL
        ```

        Добавьте соответствующую строку в конфигурацию (см. раздел выше) и
        перезапустите терминал. Проверьте, что автодополнение работает,
        набрав `uv ` и нажав `Tab`.

    4. **Изучите справку** - выполните `uv help` и ознакомьтесь со списком
       доступных команд. Попробуйте получить справку по нескольким подкомандам:

        ```bash
        uv help init
        uv help add
        uv help run
        ```

    5. **Проверьте обновление** (если уже установлена не самая свежая версия):

        ```bash
        uv self update
        ```

---

## Вопросы для самопроверки

??? question "Какой способ установки uv является рекомендуемым?"
    Standalone-установщик через `curl` (Linux/macOS) или `irm` (Windows). Этот
    способ не требует предустановленного Python, устанавливает
    предкомпилированный бинарный файл и настраивает PATH автоматически.

??? question "Как обновить uv до последней версии?"
    Если `uv` установлен через standalone-установщик:

    ```bash
    uv self update
    ```

    Для обновления до конкретной версии:

    ```bash
    uv self update 0.11.0
    ```

??? question "Куда uv устанавливается по умолчанию на Linux?"
    В директорию `~/.local/bin/`. Там располагаются два бинарных файла: `uv` и
    `uvx`. До версии 0.5.0 установка производилась в `~/.cargo/bin/`.

??? question "Какая команда настраивает автодополнение в shell?"
    Для генерации скрипта автодополнения используется
    `uv generate-shell-completion <shell>`, где `<shell>` - это имя вашего shell
    (`bash`, `zsh`, `fish`, `powershell`).

    Пример для bash:

    ```bash
    eval "$(uv generate-shell-completion bash)"
    ```

    Для постоянной активации добавьте эту строку в `~/.bashrc`.

??? question "Нужен ли Python для установки uv?"
    Нет. `uv` - это нативный бинарный файл, написанный на Rust. Он не требует
    Python для своей работы. Более того, `uv` сам может
    скачивать и управлять версиями Python.
