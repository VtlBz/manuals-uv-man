!!! info "Цели модуля"
    После прохождения этого модуля вы сможете:

    - понимать иерархию конфигурации uv и приоритет источников настроек;

    - подключать приватные индексы пакетов с аутентификацией;

## Практическое задание

!!! example "Задание: Настройка конфигурации uv"

    **Часть 1. Пользовательская конфигурация.**

    Создайте пользовательский конфигурационный файл `~/.config/uv/uv.toml` с
    предпочтительными настройками:

    ```bash
    mkdir -p ~/.config/uv

    cat > ~/.config/uv/uv.toml << 'EOF'
    python-preference = "managed"
    python-downloads = "automatic"
    EOF
    ```

    Проверьте, что настройки применяются:

## Контрольные вопросы

??? question "Каков порядок приоритетов источников конфигурации?"
    От высшего к низшему:

    1. **Флаги командной строки** - наивысший приоритет;
    2. **Переменные окружения** (`UV_*`);
    3. **Проектная конфигурация** - `uv.toml` или `[tool.uv]` в
       `pyproject.toml`;
    4. **Пользовательская конфигурация** - `~/.config/uv/uv.toml`;
    5. **Системная конфигурация** - `/etc/uv/uv.toml`.

    Каждый уровень перекрывает настройки нижестоящих уровней.

??? question "Где хранится пользовательская конфигурация на Linux?"
    На Linux пользовательская конфигурация хранится в файле
    `~/.config/uv/uv.toml`.

    На macOS - аналогично: `~/.config/uv/uv.toml`.

    На Windows - `%APPDATA%\uv\uv.toml`.

    На пользовательском уровне допускается **только формат `uv.toml`**,
    использовать `pyproject.toml` нельзя.

??? question "Как настроить аутентификацию для приватного индекса?"
    Рекомендуемый способ - **переменные окружения**:

    ```bash
    export UV_INDEX_COMPANY_USERNAME="deploy-user"
    export UV_INDEX_COMPANY_PASSWORD="deploy-token"
    ```

    Имя переменной формируется из имени индекса (в верхнем регистре, дефисы
    заменяются на подчеркивания).

    Другие способы:

    - файл `~/.netrc` с учетными данными для хоста;
    - интеграция с `keyring`;
    - учетные данные в URL (не рекомендуется из соображений безопасности).

??? question "В чем разница между флагами `default` и `explicit` для индексов?"
    **`default = true`** - индекс становится основным, **заменяя PyPI**. Все
    пакеты ищутся в нем по умолчанию. PyPI не используется, если не добавлен
    отдельно.

    ```toml
    [[tool.uv.index]]
    name = "company"
    url = "https://pypi.company.com/simple/"
    default = true
    ```

    **`explicit = true`** - индекс используется **только для пакетов, которые
    явно на него ссылаются** через `[tool.uv.sources]`. Все остальные пакеты
    продолжают устанавливаться из PyPI.

    ```toml
    [[tool.uv.index]]
    name = "pytorch"
    url = "https://download.pytorch.org/whl/cu118"
    explicit = true

    [tool.uv.sources]
    torch = { index = "pytorch" }
    ```

??? question "Как соотносятся uv.toml и секция [tool.uv] в pyproject.toml?"
    Оба формата содержат **одинаковые настройки**. Различия:

    - в `uv.toml` настройки размещаются на верхнем уровне (без префикса
      `[tool.uv]`);
    - в `pyproject.toml` все настройки uv находятся внутри секции `[tool.uv]`.

    Если в директории проекта существуют оба файла, **`uv.toml` имеет
    приоритет**, а `[tool.uv]` в `pyproject.toml` полностью игнорируется.
    Рекомендуется использовать только один из форматов.

    На пользовательском и системном уровнях допускается только `uv.toml`.
