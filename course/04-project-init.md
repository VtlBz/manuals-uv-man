## Контрольные вопросы

??? question "В чем различие между `--app` и `--lib`?"
    `--app` создает приложение: плоская структура с `hello.py` в корне, без
    секции `[build-system]`. Проект не предназначен для публикации в PyPI.

    `--lib` создает библиотеку: `src/`-layout с `__init__.py` и `py.typed`, есть
    секция `[build-system]` с бэкендом сборки. Проект можно
    собрать и опубликовать как пакет.

??? question "Нужно ли коммитить `uv.lock` в Git?"
    Да, обязательно. `uv.lock` обеспечивает воспроизводимость сборки: все
    разработчики и CI-серверы получают одинаковый набор пакетов с точными
    версиями. Без lockfile в репозитории разные участники команды могут
    получить разные версии зависимостей.

??? question "Что произойдет с существующими настройками `[tool.ruff]`, если выполнить `uv init` в директории?"
    Ничего. Команда `uv init` добавляет секции `[project]` и другие
    uv-специфичные данные, но не затрагивает секции `[tool.*]`. Все настройки
    Ruff, mypy, pytest и других инструментов остаются без изменений.

??? question "Для чего нужна секция `[build-system]`?"
    Секция `[build-system]` указывает, какой бэкенд использовать для сборки
    пакета (wheel/sdist). Она нужна библиотекам, которые публикуются в PyPI.
    Приложениям, которые не публикуются как пакеты, эта секция не требуется.

??? question "Чем `[dependency-groups]` отличается от `[project.optional-dependencies]`?"
    `[dependency-groups]` (PEP 735) - это группы для организации рабочего
    процесса разработчиков (dev, test, lint, docs). Они не
    устанавливаются при `pip install mypackage`.

    `[project.optional-dependencies]` - это extras, предназначенные для конечных
    пользователей библиотеки. Они устанавливаются через
    `pip install mypackage[extra]` или `uv add "mypackage[extra]"`.
