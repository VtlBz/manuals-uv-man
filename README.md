# uv - Руководство для Python-разработчиков

> [English version](README.en.md)

Данный репозиторий содержит исходные материалы
практического руководства по [uv](https://docs.astral.sh/uv/) - современному
менеджеру пакетов и проектов для Python от команды [Astral](https://astral.sh/).

Руководство охватывает работу с `uv` от установки и базовых команд до продвинутых
сценариев: управление версиями Python, зависимости, окружения, sync-workflow,
Docker/CI, workspaces, публикация пакетов. Материал написан на русском языке,
оформлен в Markdown и собирается в статический сайт через MkDocs Material
для публикации через любую совместимую static-hosting платформу
(GitHub Pages, GitLab Pages, Netlify и т.д.).

Помимо руководства, в репозитории хранятся вспомогательные материалы для создания
обучающего курса по `uv` (практические задания, вопросы для самопроверки).

## Для кого

Python-разработчики, которые:

- работают с `requirements.txt`, `pip-tools`,
  `pyenv`, `poetry` и хотят перейти на `uv`;
- ищут единый инструмент для управления
  Python-проектами.

## Структура репозитория

В `docs/` находится основное руководство - 15 разделов в формате Markdown.
Из этих файлов собирается статический сайт документации.

В `course/` хранятся вспомогательные материалы для создания обучающего
курса на основе руководства: практические задания и вопросы для самопроверки,
сгруппированные по разделам.

Остальные файлы - конфигурация проекта:

```text
mkdocs.yml      конфигурация MkDocs Material
pyproject.toml  зависимости проекта (uv-managed)
uv.lock         lockfile зависимостей
```

## Как собрать локально

Проект управляется через `uv`. Для локальной сборки и просмотра:

```bash
uv sync --group docs
uv run mkdocs serve
```

Сайт будет доступен по адресу `http://127.0.0.1:8000/`.

Для статической сборки:

```bash
uv run --group docs mkdocs build --strict
```

## Публикация

Репозиторий не навязывает конкретный CI/CD-пайплайн для публикации.
Для деплоя настройте workflow под вашу платформу (например, GitHub Pages)
и используйте команду сборки:

```bash
uv run --group docs mkdocs build --strict
```

## Об авторстве

Концепция руководства, его структура, стиль изложения и редакторские решения
принадлежат автору. При подготовке текста использовались инструменты
генеративного ИИ в качестве вспомогательного средства для подготовки черновых текстов,
которые затем вычитывались, корректировались и компоновались автором.
